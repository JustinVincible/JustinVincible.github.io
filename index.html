One agent, three parts

COMPASS

Grid or nodes? How a world model should remember objects it can't see

A robot that turns away from a moving cart still needs to know where the cart went. FloWM, a recent world model from ICML 2026, keeps hidden objects in a dense top-down feature grid that it shifts with five built-in velocities. I reproduced FloWM to its published error and compared it with a node memory that stores each object's position and velocity explicitly, as a Kalman-filtered belief.

The comparison also showed how much a memory score depends on the probe that reads it: a single-cell probe finds 66% of out-of-view blocks where a rebuild of FloWM's own probe finds 89%. Both memories generalize only as far as their motion prior reaches, but a node memory's prior can be refit without labels. I'm now building a learned node memory whose cost grows with the number of objects, not the size of the room.

94% vs 4%of hidden blocks found on motion outside FloWM's built-in velocities, in a pre-registered, independently verified test on 1,024 held-out videos. The node memory gets oracle detections; FloWM works from pixels.
14 KBof memory state for the node memory, against 5.6 MB for FloWM's grid.

Workshop paper “Grid or Nodes?” at CoRL 2026, Do Robots Need World Models? Preprint coming soon.

2026 – present Perception In preparation

SP-JEPA

Do superpixel tokens change what a JEPA learns? A controlled study

Vision transformers cut images into a fixed grid that ignores object boundaries. Superpixels follow edges, so they looked like a natural fit for object-centric encoders and world models. I built SP-JEPA, an I-JEPA-style encoder that reads SLIC superpixel tokens, and a grid twin that differs only in the partition, then trained an 18-run matrix from ViT-Tiny to ViT-Base and from ImageNet-100 to ImageNet-1K.

I started out expecting superpixels to win. Matched controls turned the project into a sharper question, and the answer so far is no: the two encoders tie, grid features read out on superpixels do just as well as superpixel features, and superpixel shape handed to the predictor becomes a shortcut rather than a feature.

Tiebetween superpixel and grid encoders on VOC segmentation. Neither leads by the pre-registered bound, over 3 training seeds and 5 probe seeds each.
−3.4 to −5.0ImageNet-100 points lost when region shape is written into the tokens.
2026 – present Metacognition Active

PONDER

When should an agent ask an LLM, and what should it ask?

A language model knows a lot about worlds in general and nothing about this one in particular. PONDER puts an agent with a planner and a map memory into Craftax, a fast Minecraft-like game, and lets it pay to ask a frozen LLM what to do next, how to get an item, where something is, or why an action failed. The world decides whether the advice was right. To test advice that is confidently wrong, I built counterfactual worlds with altered crafting rules.

A power analysis on about 179,000 real decision states showed, before any cluster compute was spent, that a learned policy could not yet tell a useful question from noise. The project is now a controlled study of when asking pays.

+11 pointsof diamond success when the agent asks at planning events, in a pre-registered recheck over 200 paired episodes (one-sided p = 0.004).
59%of the advisor's recipe answers were contradicted by counterfactual worlds on the iron-pickaxe task, where asking made the agent worse.

2025 – present Drone lidar, interior Alaska In preparation

Preserving vertical structure for permafrost thaw mapping

3D-to-2D projection with learned height embeddings

Most point-cloud-to-raster pipelines flatten away the vertical structure of a forest, which is exactly the signal that relates to what is happening in the ground below. This model pairs a Point Transformer V3 encoder with a projection decoder that uses learned height embeddings and z-stratified sampling to keep that structure, and predicts thaw and heave maps from drone lidar.

I compared it with PointPillars- and BEVFusion-style projections on a shared encoder, using data collected with collaborators at a US Army Corps of Engineers field site near Fairbanks. A journal version for IEEE Transactions on Geoscience and Remote Sensing is in preparation.
